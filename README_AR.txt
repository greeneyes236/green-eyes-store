جرين آيز للعدسات اللاصقة الطبية - نسخة بداية تجريبية

المحتويات:
- متجر متجاوب باللغة العربية.
- زر طلب واتساب مربوط مبدئياً بالرقم 201551730902.
- إضافة وحذف منتجات وصور من لوحة تجريبية.
- أساس PWA لإمكانية تثبيت الموقع كتطبيق على الهاتف.
- مكان مخصص لإدخال Meta Pixel ID.

مهم جداً قبل النشر:
1) هذه نسخة واجهة أولية وليست متجر إنتاج جاهزاً.
2) لوحة الإدارة الحالية تحفظ المنتجات داخل متصفح الجهاز فقط (localStorage)، وليست آمنة ولا تزامن المنتجات بين الأجهزة.
3) يجب إضافة Backend وقاعدة بيانات وتخزين صور آمن وتسجيل دخول مدير قبل فتح لوحة الإدارة للعامة.
4) إدخال Pixel ID وحده لا يفعّل البيكسل في هذه النسخة؛ يجب إضافة كود Meta الرسمي وربط الأحداث بعد تحديد الدومين وسياسة الموافقة على التتبع.
5) يمكن تثبيت الموقع كتطبيق PWA بعد رفعه على HTTPS. إنشاء APK مستقل يحتاج خطوة تغليف إضافية (مثل Capacitor أو Android Trusted Web Activity) واختباراً قبل التوزيع.
6) الاستضافة المجانية لها حدود استخدام وتخزين ونقل بيانات وقد تتغير شروطها.

للتجربة:
افتح index.html عبر خادم محلي أو ارفع الملفات إلى استضافة HTTPS ثابتة.
لا تضع بيانات حساسة أو تترك زر إدارة المتجر متاحاً للعامة في نسخة الإنتاج.
